# Blanktab

Replaces Chrome's new tab page with a blank page that shows only your own note: a quote, a goal or a few links.

## Features

- Write a title and a note. Links in the note can be clicked.
- Set the background color, text color and text size from the toolbar popup.
- Your settings are saved in Chrome's storage.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose this folder.

## Built with

JavaScript and the Chrome Extensions API (Manifest V3).
